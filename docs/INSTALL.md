# 未公証版のインストール

公開ベータ版は [2ndNuts/skill-pallet-releases](https://github.com/2ndNuts/skill-pallet-releases/releases/tag/v0.3.6-beta.1) から入手できます。利用者向けの手順は[公開ガイド](https://github.com/2ndNuts/skill-pallet-releases/blob/main/INSTALL.md)を参照してください。

以下は、非公開の開発スナップショット `0.3.6-dev.1` を扱う場合の手順です。

対象：Apple Silicon搭載Mac、macOS 14以降、Codexデスクトップアプリ。

現在の開発版はDeveloper ID署名・Appleの公証を受けていません。入手元を信頼でき、ファイルが改ざんされていないことを確認したうえで、そのアプリを開くか判断してください。別のMacでの初回起動・入力はまだ検証していません。

## ダウンロード

1. `2ndNuts/skill-pallet` のReleaseから `Skill-Pallet-0.3.6-arm64-development.zip` と `SHA256SUMS.txt` を入手します。
2. 必要に応じてZIPのSHA-256を添付のチェックサムと照合します。
3. ZIPを展開し、`Skill Pallet.app` を「アプリケーション」フォルダへ移します。

現在のリポジトリは非公開で、Releaseは下書きです。ダウンロードできる範囲はリポジトリと下書きへのアクセス権に従います。

## 初回に開く

1. Finderから `Skill Pallet.app` を開きます。
2. 開発元や公証を確認できないという警告で止まった場合は、いったん警告を閉じます。
3. 「システム設定 → プライバシーとセキュリティ」を開きます。
4. Skill Palletがブロックされた旨の表示を確認し、「このまま開く」を選びます。
5. 再度の確認で、実行する意思がある場合は「開く」を選びます。認証が求められた場合は利用者自身で行います。

この個別許可は[Appleが案内する手順](https://support.apple.com/ja-jp/102445)です。管理対象のMacでは利用できない場合があります。破損・改ざん・既知のマルウェアに関する警告の場合は実行を進めず、配布元へ連絡してください。

## Codexへ入力するための許可

初回起動の個別許可とは別に、「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でSkill Palletを許可します。

Codexを開き、Skill Palletの更新ボタンからカタログ作成を依頼します。入力欄へ追加された依頼を確認して送信すると、作成されたカタログをSkill Palletが読み込みます。スキルのチップを押すと入力欄の末尾へ追記し、送信は行いません。

## アップデート

Skill Palletを終了してから、ダウンロードした新しいアプリへ置き換えます。カタログと使用履歴はアプリの外に保存されます。未公証の開発版では、更新により初回起動の個別許可やアクセシビリティの再登録を求められる場合があります。
