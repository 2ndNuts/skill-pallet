# スキルカタログ

カタログは利用者ごとのJSONファイルです。スキル名、概要、呼び出し名、ジャンル、検索タグをまとめ、アプリから独立して管理します。

保存先：`~/Library/Application Support/Skill Pallet/catalog.json`

更新用プロンプトのパスは、利用者ごとの保存先とアプリの起動場所から生成します。ホームディレクトリ配下は `~/...` と表示します。検証コマンドの場所も、起動したアプリに応じて変わります。

## 更新

1. Skill Palletの上部にある更新ボタンを押します。
2. Codexの入力欄に追加された依頼を確認し、送信します。
3. Codexが利用可能なスキルを整理し、カタログを保存します。
4. Skill Palletがファイルの変更を検知して一覧を読み直します。

「カタログ」メニューから、依頼のコピー、ファイルの再読み込み、保存場所の表示もできます。

初めて使うときは、空の一覧からカタログの作成を依頼できます。書式に問題がある場合は案内を表示し、直前の正常な一覧を保持します。アプリを開き直した場合も、正常な一覧の控えを読み込めます。控えは同じフォルダの `.catalog-last-valid.json` に保存されます。

## 形式

```json
{
  "schemaVersion": 1,
  "skills": [],
  "warnings": []
}
```

`skills` の各項目には、以下のフィールドが必要です。

| フィールド | 内容 |
| --- | --- |
| `id` | SKILL.mdの絶対パス |
| `name` | 表示するスキル名 |
| `invocation` | Codexで指定する名前。提供元の接頭辞を含み、先頭の `/`・`$` は付けない |
| `summary` | 日本語の1行概要 |
| `description` | 元の説明文 |
| `source` | 提供元の表示名 |
| `genres` | ジャンルの文字列配列。少なくとも1つ |
| `tags` | 検索用の文字列配列。空でもよい |

ジャンルは `audio`（音）、`video`（映像）、`image`（画像）、`ui`（UI・Web）、`words`（調査・文章）、`data`（資料・データ）、`organize`（整理・連携）です。複数のジャンルを設定すると、それぞれの一覧に表示されます。タグは検索に使い、チップには表示しません。

同じパス、または同じ `invocation` と `source` の組み合わせは重複させません。同じスキルを更新するときは `invocation` と `source` を維持することで、使用回数とお気に入りを引き継げます。よく使う順で使用回数が同じ場合は、カタログの並び順を使います。

ファイルは8MB以内、スキルは10,000件以内です。概要は500文字以内、検索タグは1つ80文字以内・32個以内。`warnings` には、更新時に確認できなかった点を文字列で保存できます。

## 検証用コマンド

アプリの実行ファイルに `--validate-catalog` とJSONのパスを渡すと、画面を開かずに形式と重複を検証します。成功時は終了コード0、失敗時は1です。ファイルは変更しません。

`--catalog-prompt` では、更新用の依頼文を標準出力へ表示します。
