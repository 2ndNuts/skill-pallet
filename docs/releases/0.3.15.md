# Skill Pallet 0.3.15

チップの一覧上で横方向にスクロールすると、隣のジャンルへ切り替わります。トラックパッドでは左へフリックすると次、右へフリックすると前のジャンルへ移動します。順番は上部のボタンの並びと同じで、「すべて」から「整理・連携」までです。端では止まります。

1回のフリックで移動するのは1ジャンルです。慣性が残っていても、そのまま何ジャンルも進みません。検索語、お気に入りの絞り込み、並び順を引き継ぎます。

縦方向は従来の慣性スクロールで一覧を移動します。操作の途中で縦横を切り替えず、斜め入力や小さな揺れでジャンルを変えないようにしています。縦にスクロールできない短い一覧でも、横フリックは利用できます。

## 検証

画面側63件と、パッケージ化したアプリの自己検証が通過しました。縦方向の慣性、1フリック1ジャンル、斜め入力、短い一覧、端での停止、入力処理中の抑制、慣性や古い入力による遅れた切り替えを確認しています。利用者による実操作でも、横フリックで切り替わることを確認しました。
