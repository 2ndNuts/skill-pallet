# Skill Pallet 0.3.9

アクセシビリティを許可しているのに「チャットの入力欄が見つかりません」と表示されるケースに対応しました。

新しいCodexデスクトップアプリで従来の情報公開用属性が使えない場合、対応する別方式へ切り替えます。入力欄の情報が公開されるまでの待ち時間にも対応しました。初回の有効化を同じプロセスへ繰り返し要求しないため、次の追記ではこの待ち直しを省きます。

入力先の選別と下書きの保護は維持しています。0.3.7で修正した末尾改行の照合も引き継ぎ、送信操作は行いません。診断には候補の数・種類・API返値を記録し、下書き本文は記録しません。

## 検証

情報公開をOFFにしたElectron検証アプリで、代替方式による有効化、空欄への連続追記、2回目の初期化省略を確認しました。文書・コード編集欄・検索欄への入力拒否と、下書き変更時の中止も確認しています。

2026年10月26日、利用者の操作で実際のCodexへの追記と「追加しました」の表示を確認しました。自動テストには検証用アプリを使っています。

開発上の参照：[Electronのアクセシビリティ](https://github.com/electron/electron/blob/main/docs/tutorial/accessibility.md)、[ChromiumのmacOS実装](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/chrome/browser/chrome_browser_application_mac.mm)。
