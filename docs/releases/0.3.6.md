# Skill Pallet 0.3.6 — 開発版

公開ベータ版は [0.3.6 Beta 1](https://github.com/2ndNuts/skill-pallet-releases/releases/tag/v0.3.6-beta.1) です。このページは非公開の開発スナップショットについての記録です。

Apple Silicon / macOS 14以降 / Codexデスクトップアプリ向け。

## 内容

- 木製チップ、検索、ジャンル、お気に入り、関連スキルのスタック。
- 外部カタログとCodexへのカタログ更新依頼。
- 直近30日の使用回数を保存し、木の色を5段階で変更。
- スクロールとウィンドウ移動に対する個別の慣性・摩擦・衝突、接触時の木の音。
- 起動・再表示・更新時の整列、ホバー・押下・展開・絞り込みの動き。

## 検証

フロントエンド38件のテストと、ネイティブの入力選別・下書き保持・クリップボード復元・保存・カタログ・ウィンドウ制御の自己検証を通過しています。開発環境では起動、検索、スクロール、スタック開閉を確認しています。

## 配布の状態

この版はDeveloper ID署名・Appleの公証を受けていません。未公証版をZIPで配布する方式ではApple Developer Programへの加入は不要ですが、初回起動時に利用者による個別許可が必要です。

[インストールと初回起動の手順](https://github.com/2ndNuts/skill-pallet/blob/main/docs/INSTALL.md)を用意しています。別のMacでの初回起動と入力は未検証です。現在は非公開のRelease下書きで準備している開発確認用の版です。
