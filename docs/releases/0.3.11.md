# Skill Pallet 0.3.11

チップを押したときの反応を改善しました。

押した瞬間からチップと文字が一緒に沈み、トレーに着いた後、滑らかに元の高さへ戻ります。短いクリックでも約70msは押下の反応が残ります。ホバーする間もなく押した場合にも沈む余地を設け、皿の内側の陰影も接触に合わせて変えています。

この動きは入力処理と同時に始まります。演出のための入力待機はありません。入力中にボタンが無効になったり、フォーカスがCodexへ移ったりしても、押下の動きは途切れません。

チップの外で離すと操作を取り消します。Enter・Spaceでも押下と解除に反応し、キーを離したときに一度だけ入力します。動きを減らす設定ではチップを移動させず、接触の陰影だけを表示します。

## 検証

46件のテストが通過しました。実際のThree.jsの形状・変換・文字投影を使った計算検証では、短いクリックの沈み込みが従来の約0.05pxから約2.5pxになりました。木片の伸縮や隣のチップの移動はありません。この計算検証のGPU描画は代替しています。

内蔵ブラウザでは、実際のGPU描画と入力中のボタン無効化を確認しました。検証用の入力先への要求はクリック後約0.2〜1.3msで始まり、押下の描画を待ちません。外へドラッグした操作の取消、Enter・Spaceによる一度だけの要求も確認しています。実チャットへの追記はこのブラウザ検証では実行していません。
