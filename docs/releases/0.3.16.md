# Skill Pallet 0.3.16

横フリックとジャンルボタンの選択で、木のトレーと4×4のチップが横へ切り替わります。トレーは200msで滑らかに減速し、中のチップはそれぞれの慣性・摩擦・衝突によって収まります。木の音は、画面に見えている接触に連動します。

ロゴ、検索、ジャンルボタン、件数、並び順、概要欄の位置は固定です。移動中に別のジャンルを選ぶと、現在の移動が終わってから最後に選んだジャンルへ進みます。検索語、お気に入りの絞り込み、並び順を引き継ぎます。

移動中のチップは選択を一時停止し、トレーが止まると操作を再開します。macOSで「動きを減らす」を有効にしている場合は、横移動とその衝突音を省いて一覧を切り替えます。

## 検証

画面側69件のテストで、200msの停止、連続操作の最後の選択、方向反転、キャンセル、個別の衝突、音の間隔、縦スクロールとの共存を確認しています。内蔵ブラウザでは112件の架空のスキルを使い、出入りするトレー、文字の投影、外側の固定、停止後の操作復帰を確認しました。
