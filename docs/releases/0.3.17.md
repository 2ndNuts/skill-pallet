# Skill Pallet 0.3.17

軽い横フリックと、続けて行うフリックへの反応を改善しました。Mac版は指の操作と慣性を区別し、前の慣性が残っていても次のフリックを受け付けます。ブラウザ版は移動量と加速から次の操作を判定します。

切り替えに必要な横移動は12px、短く速いフリックでは6pxから判定します。横方向の判定は4pxから行い、ごく小さな斜め入力で縦スクロールへ固定してしまう状態も修正しました。

トレーの移動時間は200msです。1回のフリックで1ジャンルだけ進み、そのフリックの慣性だけでは続けて切り替わりません。移動中に次の操作を受けた場合は、現在の移動を完了してから最後に選んだジャンルへ進みます。チップごとの慣性と衝突音、縦スクロール、検索・お気に入り・並び順は引き継ぎます。

## 検証

画面側84件のテストと、Macアプリの自己検証が通過しています。短く速い入力、同方向の連続フリック、逆方向への切り返し、慣性による多重切り替えの抑制、縦スクロールを確認しています。Macの入力時刻と画面側の時刻が異なる場合や、同じ入力の二重処理も検証しています。ブラウザのトラックパッドによる連続操作は利用者が確認しています。Mac版での連続操作の感触と、別のMacでの初回起動・入力は未検証です。

アプリ内のバージョンは0.3.17、ビルドは32です。配布名は0.3.17 Beta 1です。
