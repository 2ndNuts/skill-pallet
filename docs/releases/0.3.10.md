# Skill Pallet 0.3.10

スキルを選んでから入力欄へ反映するまでの待ち時間を短縮しました。入力先がアクティブになり、カーソルが末尾にあることを確認できたら貼り付け、反映結果も確認できた時点で成功表示へ進みます。

ピン留めがOFFでも、入力処理の間はパレットを手前に保ちます。完了後は保存済みのピン設定に戻ります。処理中に自分で閉じたウィンドウは開き直しません。

入力欄の情報が初めて公開される際には、初期化の待ち時間が加わります。下書きの保護、クリップボードの復元、成功後の使用回数の保存は従来どおりです。

## 検証

独立したElectronの検証アプリで比較しました。旧版ではピンOFFのパレットが入力先の後ろに隠れ、初期化後の完了時間は約481〜484msでした。

修正版は連続5回の入力中にパレットの遮蔽を検出せず、完了後はピンOFFに戻りました。初回を除く4回の貼り付け命令までの時間は45〜55ms、成功確認まで92〜123msでした。60Hzの画面に換算すると、それぞれ約3フレーム、約6〜8フレームです。これは検証アプリの計測であり、実際のCodexの描画時間は含みません。

日本語・英語の空欄と下書き、遅延表示、長い履歴を含む10ケースが通過しました。文書・コード編集欄・検索欄への入力は拒否しています。情報公開をOFFにした検証では初回が約2.37秒、2回目が約145msで完了し、両方ともパレットは画面上に残り、透明度も変化しませんでした。初回の情報公開要求を2回目に繰り返さないことも確認しています。

2026年10月26日、実際のCodexへの入力と、入力時にパレットが消えないことを利用者の操作で確認しました。そのときの診断は貼り付け命令まで82ms、反映確認まで172msでした。
