複数ジャンルのスキルは、絞り込んだジャンルの色で表示します。「すべて」の一覧では、カタログで先頭にあるジャンルを使います。スタックは最初の表示メンバーに合わせます。「すべて」のボタンは中立の木色です。

## 検証

画面側53件と、パッケージ化したアプリの自己検証が通過しました。7色の割り当て、複数ジャンルの切り替え、スタックの色、元のカタログ情報を維持することを確認しています。使用中の119スキルでも、各ジャンルで表示される項目と配色を照合しました。更新したアプリで全ジャンルの切り替え、画像チップの縁と概要のコーラル色、ロゴと音量アイコンの表示も確認しました。
