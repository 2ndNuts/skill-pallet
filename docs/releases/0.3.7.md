# Skill Pallet 0.3.7

スキルが入力欄へ追加されているのに、「入力結果を確認できませんでした」と表示されるケースを修正しました。

入力欄のアクセシビリティ情報では、追記前に見えていた段落末尾の改行が、追記後に省かれることがあります。末尾位置を確認できた場合に限り、この表現の差を許容します。既存の下書きやユーザーの改行は引き続き照合します。成功を確認すると通常の完了表示・使用回数の保存へ進み、操作音がONの場合は成功音へつながります。

## 検証

空欄、既存の下書き、日本語・絵文字、複数段落、末尾の区切りスペースとNBSP表現を確認しています。別のコマンド、本文の変化、ユーザーの改行の欠落、余分な文字は成功と扱いません。成功表示・使用回数の一度だけの保存、クリップボード復元、ウィンドウ表示維持の自己検証もDebugビルドと最適化ビルドで通過しました。

実際のCodexへの自動入力は行わず、保存された文字数診断と検証用データで確認しています。
