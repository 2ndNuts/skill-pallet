# Skill Palletのインストール

対象：Apple Silicon搭載Mac、macOS 14以降、Codexデスクトップアプリ。

このベータ版はAppleのDeveloper ID署名・公証を受けていません。入手元とファイルを確認し、実行するかを利用者自身で判断してください。別のMacでの初回起動・入力は未検証です。

## 1. ダウンロード

1. [GitHubのリリースページ](https://github.com/2ndNuts/skill-pallet-releases/releases/tag/v0.3.16-beta.1)を開きます。
2. Assetsから `Skill-Pallet-0.3.16-beta.1-arm64.zip` をダウンロードします。
3. ZIPを展開し、`Skill Pallet.app` を「アプリケーション」フォルダへ移します。

ZIPにはアプリ、利用手順、クレジットが入っています。個人のスキルカタログや使用履歴は同梱していません。

整合性を確認する場合は、同じリリースの `SHA256SUMS.txt` とZIPのSHA-256を照合できます。

## 2. 初回に開く

1. Finderから `Skill Pallet.app` を開きます。
2. 開発元や公証を確認できない旨の警告で止まったら、いったん警告を閉じます。
3. 「システム設定 → プライバシーとセキュリティ」を開きます。
4. Skill Palletがブロックされた旨の表示を確認し、「このまま開く」を選びます。
5. 再度の確認で実行する意思がある場合は「開く」を選び、認証が求められたら利用者自身で行います。

このアプリごとの許可は[Appleが案内する手順](https://support.apple.com/ja-jp/102445)です。管理対象のMacでは利用できない場合があります。破損・改ざん・既知のマルウェアに関する警告の場合は実行を進めず、[配布元へ報告](https://github.com/2ndNuts/skill-pallet-releases/issues)してください。

## 3. Codexへ入力するための許可

1. 「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でSkill Palletを許可します。
2. Codexでチャットを開きます。
3. Skill Palletの↻からカタログ作成を依頼します。入力欄に追加された依頼を確認して送信します。
4. カタログが反映されたら、チップを押します。現在のチャットの入力欄へ追記されます。

Skill Palletは送信操作を行いません。入力先が見つからない場合は、Codexの入力欄を一度クリックしてからチップを押してください。

## アップデート

Skill Palletを終了してから、新しいアプリへ置き換えます。カタログと履歴はアプリの外に保存されます。更新により初回起動の個別許可やアクセシビリティの再登録が必要になる場合があります。

## 起動しない・入力できないとき

対応するMacとmacOSか、Codexが起動しているか、アクセシビリティで現在のSkill Palletが許可されているかを確認してください。

解決しない場合は[Issues](https://github.com/2ndNuts/skill-pallet-releases/issues)に、アプリのバージョン、macOSのバージョン、行った操作、表示された案内をお知らせください。
