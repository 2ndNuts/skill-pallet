# 変更履歴

## 0.3.6 Beta 1 — 2026-10-24

Skill Palletの初回公開ベータです。アプリ内のバージョンは0.3.6、ビルドは20です。

- 4列の木製チップ、検索、ジャンル、お気に入り、関連スキルのスタック。
- Codexの現在の入力欄への追記。入力形式は `/スキル名`、`$スキル名`、ファイル参照から選択。
- 利用者ごとの外部カタログと、Codexへのカタログ更新依頼。
- 直近30日の使用回数の保存と、木の色の5段階変化。
- スクロール・ウィンドウ移動時の個別の慣性・摩擦・衝突と、接触に連動する木の音。
- 起動・再表示・更新操作時の整列、操作音と最前面固定の切り替え。

### 対応と制限

- Apple Silicon搭載Mac、macOS 14以降、Codexデスクトップアプリ向けです。
- AppleのDeveloper ID署名・公証は受けていません。初回起動には利用者による個別許可が必要です。
- 別のMacでの初回起動と入力は未検証です。
- アプリ本体の更新は手動です。更新後に起動・アクセシビリティの再許可が必要になる場合があります。
