# Skill Pallet 0.3.6 Beta 1

Codexと並べて使う、木製チップのスキルランチャーです。

**Apple Silicon搭載Mac / macOS 14以降 / Codexデスクトップアプリ向け。**

## ダウンロード

Assetsの **`Skill-Pallet-0.3.6-beta.1-arm64.zip`** をダウンロードしてください。ZIPにはアプリ、利用手順、第三者素材のクレジットを同梱しています。`SHA256SUMS.txt` でファイルの整合性を確認できます。

**この版は未公証のベータ版です。** 初回起動には、macOSの「プライバシーとセキュリティ → このまま開く」によるアプリごとの許可が必要です。Codexへ入力するには、別途アクセシビリティを許可します。

[インストールと初回起動の手順](https://github.com/2ndNuts/skill-pallet-releases/blob/main/INSTALL.md)

## 主な機能

- 4列の木製チップ、名前・用途・ジャンルでの検索、関連スキルのスタック。
- マウスオーバーで概要を表示し、Option＋クリックでお気に入りを保存。
- 現在のCodexの入力欄へスキルを追記。送信は利用者が行います。
- 直近30日の使用回数を保存し、使うほど木の色が深く変化。
- チップごとの慣性・摩擦・衝突と、接触に連動する木の操作音。

## ベータ版の状態

アプリ内のバージョンは0.3.6、ビルドは20です。開発環境で入力・保存・3D UIを検証しています。**別のMacでの初回起動と入力は未検証です。**

アプリ本体の更新は手動です。更新後に起動やアクセシビリティの再許可が必要になる場合があります。↻はスキルカタログの更新用です。
