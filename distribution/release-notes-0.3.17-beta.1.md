# Skill Pallet 0.3.17 Beta 1

短い横フリックと連続フリックへの反応を改善しました。Mac版では指の操作と慣性を区別し、前の慣性が残っていても次の操作を受け付けます。

木のトレーが200msで切り替わる動き、チップごとの慣性・衝突音、縦スクロールは引き継ぎます。1回のフリックで移動するのは1ジャンルです。移動中の次の操作は、現在の移動が終わってから最後の選択へ進みます。

## ダウンロード

Assetsから **`Skill-Pallet-0.3.17-beta.1-arm64.zip`** をダウンロードしてください。アプリ、利用手順、ライセンスを同梱しています。`SHA256SUMS.txt`でファイルの整合性を確認できます。

**Apple Silicon搭載Mac / macOS 14以降 / Codexデスクトップアプリ向けの未公証ベータ版です。** 初回起動とアクセシビリティの許可は、[インストール手順](https://github.com/2ndNuts/skill-pallet-releases/blob/main/INSTALL.md)を確認してください。アプリ本体は終了後に新しい版へ置き換えます。

アプリ内のバージョンは0.3.17、ビルドは32です。画面側84件のテストと、パッケージ化したアプリの自己検証を実施しています。ブラウザでの連続フリックは利用者が確認しています。Mac版での連続操作の感触と、別のMacでの初回起動・入力は未検証です。
