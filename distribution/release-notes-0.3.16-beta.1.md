# Skill Pallet 0.3.16 Beta 1

木のトレーごとジャンルを切り替える横フリックと、Codexへの追記の改善を含む更新です。

**Apple Silicon搭載Mac / macOS 14以降 / Codexデスクトップアプリ向け。**

## ダウンロード

Assetsから **`Skill-Pallet-0.3.16-beta.1-arm64.zip`** をダウンロードしてください。アプリ、利用手順、ライセンスと第三者素材のクレジットを同梱しています。ファイルの整合性は、同じリリースの`SHA256SUMS.txt`で確認できます。

**この版は未公証のベータ版です。** 初回起動には利用者によるアプリごとの許可が必要です。Codexへの入力には、別途アクセシビリティを許可します。

[インストールと更新の手順](https://github.com/2ndNuts/skill-pallet-releases/blob/main/INSTALL.md)

## 0.3.6 Beta 1からの変更

- 横フリックやジャンルボタンで、木枠と4×4のトレーを200msで切り替え。各チップの慣性と、接触に連動する木の音を残します。
- 連続操作では最後に選んだジャンルへ進み、検索・お気に入り・並び順を引き継ぎます。
- 7ジャンルをそれぞれの縁色で表示し、ジャンルボタンや概要の印と統一しました。
- 操作音をOFF・標準・大の3段階にし、スピーカーアイコンで表示します。
- 空の入力欄の検出と、追記結果の確認を改善しました。入力中もパレットを表示し、短いクリックの押下を分かりやすくしました。

## ベータ版の状態

アプリ内のバージョンは0.3.16、ビルドは31です。画面側69件のテストと、パッケージ化したアプリの自己検証を実施しています。**別のMacでの初回起動と入力は未検証です。**

アプリ本体の更新は、終了後に新しいアプリへ置き換えます。更新後に起動やアクセシビリティの再許可が必要になる場合があります。↻はスキルカタログの更新用です。
